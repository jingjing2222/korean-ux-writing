# 단계별 검토 경로

시작점은 [SKILL.md](../SKILL.md)다. 현재 단계의 문서만 읽고 결과를 넘긴다. 이 파일을 전체 지침을 한꺼번에 읽는 목록으로 사용하지 않는다.

1. [맥락 파악](context.md): 독자·과업·경로·원문·사실·남은 질문을 기록한다.
2. [의미 진단](diagnosis.md): 맥락과 UX 근거로 필요한 안내를 정하고 현재 한국어를 진단한다.
3. [윤문](revision.md): 확인한 의미 차이를 해결한 뒤 한국어 표현을 다듬는다.
4. [재검증](verification.md): 같은 경로에서 결과를 확인하고 미해결 문제를 보고한다.

## 읽는 범위와 수정하는 범위

다른 언어도 맥락으로 읽지만 기존 한국어만 고친다. 자세한 구분은 1단계의 [범위 안내](context.md#읽는-범위와-수정하는-범위)에 있다. 별도 언어 작업은 사용자가 요청한 범위에서만 수행한다.

근거가 부족하면 관련 질문으로 돌아가 확인한다. 단계 전환은 승인 요청이 아니며 기존 권한 안에서 진행한다. 전체 절차는 작업 구성이고, 문구 품질의 기준은 원래 UX·한국어 출처에서 가져온다.
