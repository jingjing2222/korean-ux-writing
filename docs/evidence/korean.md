# 한국어 윤문의 근거

이 축은 한국어로 만든 제품에서 UX 역할과 실제 동작이 요구하는 의미를 **어떻게 표현할지** 판단하는 데 사용한다. 영어 원문을 전제하지 않으며, 문장을 더 짧고 친근하게 만드는 것 자체를 목표로 삼지 않는다. 아래는 확인한 외부 문서를 문제 유형에 연결한 운영상 분류이며, 새로운 언어 규칙 목록이 아니다.

[의도·맥락 우선 진단 근거](intent-first.md)에서 과업에 필요한 뜻과 현재 한국어를 먼저 대조한다. [직역체의 문장 구조 검사](translationese.md)는 이를 보조한다. 의미·행동이 어긋난 문구의 어미만 다듬지 않는다.

## 표현별 연결

| 검토할 표현 | 원문이 뒷받침하는 범위 | 증적과 적용 제한 |
|---|---|---|
| 의미 없는 수식·반복·공허한 홍보 표현 | 불필요한 말 제거, 말로 읽기 쉬운 표현, 사용자에게 필요한 정보 전달 | [SRC-001](sources.md#src-001), [SRC-008](sources.md#src-008). 특정 브랜드 말투를 모든 제품에 강제하지 않는다. |
| 모호한 오류와 의미가 약한 서술어 | 실제 상황·행동을 정확히 설명하는 문구 | [SRC-002](sources.md#src-002), [SRC-014](sources.md#src-014). 원인·해결 행동은 확인된 제품 사실을 사용한다. |
| 직역·음역 용어, 어려운 표현 | 대상자에게 친숙한 용어인지 확인하는 사례·조사 | [SRC-010](sources.md#src-010), [SRC-044](sources.md#src-044), [SRC-047](sources.md#src-047). 모든 외래어·한자어를 금지하지 않는다. SRC-047은 일부 본문만 확인했다. |
| 버튼의 -하기 반복과 명사형 | 버튼 목적에 따른 표현 선택과 예외 | [SRC-012](sources.md#src-012), [SRC-013](sources.md#src-013). -하기나 명사형의 일괄 금지로 바꾸지 않는다. |
| 해요체·높임 정도 | 읽는 사람·상황별 말투와 부적절한 사물 높임 | [SRC-007](sources.md#src-007), [SRC-008](sources.md#src-008), [SRC-051](sources.md#src-051). SRC-007의 해요체는 해당 POS 브랜드 범위이며, -시- 전체를 제거하지 않는다. |
| 능동형·긍정형·부정형 | 제품 전용 기준과 상황별 표현 선택 | [SRC-007](sources.md#src-007), [SRC-008](sources.md#src-008), [SRC-018](sources.md#src-018). 피동·부정 표현 전면 금지의 근거가 아니다. |
| 문장 길이·정보량·구성 | 과업에 맞는 정보량, 주요 메시지, 중요한 조건의 상세한 설명 | [SRC-015](sources.md#src-015), [SRC-016](sources.md#src-016), [SRC-017](sources.md#src-017), [SRC-045](sources.md#src-045). 임의 글자 수·문장 수 제한으로 바꾸지 않는다. |
| 안내 제목·본문 연결 | 제목에 구체적인 내용을 드러내고 수신자 중심으로 설명 | [SRC-033](sources.md#src-033), [SRC-049](sources.md#src-049). 제목을 바꿀 때 실제 본문 의미를 확인한다. |
| 중요한 항목의 누락·배치 | 핵심 항목을 유지하고 구분하여 전달 | [SRC-050](sources.md#src-050). 보도자료의 확인한 발췌 범위이며 모든 UI에 보도자료 형식을 강제하지 않는다. |
| 정확성·독자 관점 | 어법·정보량·연결·권위적 표현 등을 점검하는 공공언어 기준 | [SRC-043](sources.md#src-043), [SRC-044](sources.md#src-044), [SRC-045](sources.md#src-045). SRC-043은 확인한 요건 표 범위에 한정한다. |
| 맞춤법·띄어쓰기·문장부호 | 어문 규범의 원칙·허용·예외 | [SRC-048](sources.md#src-048), [SRC-052](sources.md#src-052). UX 품질 판정과 구분하고 실제 조항·문장 구조를 확인한다. |
| 키오스크의 언어 오류·이해도 | 실제 표현 수집, 오류 유형, 고령층 이해도·수용도 조사 | [SRC-041](sources.md#src-041), [SRC-042](sources.md#src-042). UX 접근성과 겹치며 SRC-042의 구체적인 교정 결과는 추가 확인이 필요하다. |
| 평가의 구분 | 표기·표현 정확성과 소통성을 따로 다루는 연구 | [SRC-046](sources.md#src-046). 연구 점수를 모델의 자연스러움 점수로 전용하지 않는다. |

## 이 자료로 단정할 수 없는 것

출처를 연결했다는 사실만으로 개선문이 항상 우월하거나 AI slop이 사라졌다고 입증되지는 않는다. 임의의 금칙어 목록, 문장 점수, 해요체·능동형·긍정형의 일괄 강제는 위 출처가 공통으로 정한 기준이 아니다. 특히 서로 다른 제품 조직의 말투를 하나의 한국어 정답으로 합치지 않는다.

구체적인 교정에서는 원문의 주장, 적용되는 문장과 상황, 예외를 함께 기록한다. 중요한 의미·조건을 지키는지와 표현을 다듬는 이유를 구분하고, 근거가 부족하면 유지 또는 보류의 이유를 남긴다. 이 작업 절차는 해당 외부 문서가 직접 선언한 범용 규칙으로 표기하지 않는다.

원문별 주장과 확인 한계는 [출처 카드](sources.md), 상태 정의는 [증적 안내](README.md)에서 확인할 수 있다.
