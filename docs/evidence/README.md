# 외부 증적

이 디렉터리는 스킬 밖에 두는 **외부 근거 기록**이다. 문구 품질의 근거는 각 항목이 연결하는 실제 UX 지침·제품 조직의 원저술·국립국어원 자료이며, 이 레포나 다른 에이전트 스킬이 아니다.

기본 검토 대상은 처음부터 한국어로 만든 제품의 문구다. 영어 원문이나 번역 개발 과정을 전제하지 않는다. 번역·현지화 자료는 의도·맥락·어휘 적합성 원칙을 참고하는 근거이며, 이를 한국어 원문 검토에 적용하는 방식은 운영상 해석으로 구분한다. 실제 영문 자료가 있을 때만 보조 맥락으로 참조한다.

한국어 윤문 요청만으로 다른 언어를 번역·교정하지 않는 것은 사용자가 정한 작업 범위다. 외부 지침의 쉬운 표현·용어 통일 원칙이 이 범위를 넓히는 권한을 주지는 않는다. 전체 퍼널을 읽는 범위와 실제로 고치는 언어를 구분하며, 기존 외국어 표기를 보존한다.

[의도·맥락 우선 진단 근거](intent-first.md)는 윤문 전에 사용자 과업과 현재 한국어의 의미를 대조하는 기준이다. [직역체 진단 근거](translationese.md)는 이를 보완하며, 문법적 특징만으로 진단하지 않는다.

[사용자 관점과 안내 시점의 근거](user-perspective.md)는 제품 내부 맥락과 사용자에게 전달된 맥락을 구분한다. 선행 안내가 빠진 경우 현재 문구에 설명을 덧붙이는 데 그치지 않고 진입점·단계·정보 제공 순서를 검토한다.

[독자에게 필요한 뜻을 전달하는 근거](reader-language.md)는 내부 절차·추상어를 그대로 설명하는 문구와 독자가 얻어야 할 답을 구분한다. 전문 용어와 권리·이용 조건의 의미를 보존하면서 표현을 검토한다.

두 책임을 구분한다.

- **[UX 근거](ux.md):** 해당 화면·동작·상태가 사용자에게 무엇을 알려야 하는가.
- **[한국어 윤문 근거](korean.md):** 그 의미를 한국어로 어떻게 정확하고 자연스럽게 표현하는가.

제품 코드·화면·사양은 실제 동작, 조건, 결과를 확인하는 자료다. 좋은 UX나 한국어 문체의 기준으로 승격하지 않는다. 전체 과업과 실제 화면 맥락을 확인할 외부 근거를 사용하되, 퍼널 추적 범위·진단 순서·기록 형식은 이 레포의 운영 설계로 구분한다.

## 기록과 확인 상태

- [sources.json](sources.json): 87개 출처의 ID, 원문 URL, 성격, 확인 위치, 주장, 적용 범위, 한계.
- [sources.md](sources.md): 동일 ID의 직접 앵커와 원문 내용·운영상 해석의 구분.
- 자료 언어: 한국어 68개, 한국어·영어 혼합 1개, 영어 18개. 영어 자료는 지역화·사용자 여정·검증 방법을 보완하며 한국어 개별 표현의 정답으로 쓰지 않는다.
- 확인일: 2026-10-21. 이 날짜는 확인 시점이며 발행일이나 최신성 보장이 아니다.

`passage-checked`는 기록한 구절을 확인했다는 뜻이다. 전체 문서 검증, 독립적인 사용성 실험, 인간의 승인이나 인증을 의미하지 않는다. `partial`은 공식 게시물·발췌·초록 등 제한된 범위만 확인한 상태다. SRC-042·047·050·056이 해당하며, 미확인 세부 규칙·개선문·통계에 의존하는 판단은 보류한다.

같은 KRDS에 속한 22개 페이지(SRC-019~040)는 역할이 다른 문서 22개다. 서로 독립적인 연구 22건이 아니다. Microsoft 한국어 가이드의 세부 패시지도 한 출처(SRC-059)로 센다. 사례·인터뷰·전문가 제안·공식 지침·어문 규범은 같은 증명력을 갖지 않으며, SRC-074는 실제 관측 데이터가 아닌 가상 교육 사례다.

## 변경을 근거에 연결하기

적용할 때는 원문과 확인 위치를 읽고 적용 조건·예외가 맞는지 확인한다. 문구별 판정에는 UX 역할과 한국어 표현 근거를 필요한 만큼 각각 연결한다. 한 자료가 두 책임을 지원할 수 있으나, 맞춤법만 맞는다는 이유로 좋은 UX라고 판정할 수는 없다.

원문이 명시한 내용과 이 프로젝트의 운영상 해석을 구분한다. 새 규칙은 다른 스킬이나 모델의 취향에서 추가하지 않는다. 출처가 충돌하면 대상·과업·상태·문서 성격을 비교하며, 해결되지 않은 차이를 숨기지 않는다.

원문 전체를 복제하지 않고 필요한 내용을 요약한다. 이후 근거가 바뀌면 URL·확인 위치·주장·범위·한계·확인일을 함께 갱신한다.
