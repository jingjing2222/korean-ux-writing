# 외부 증적

이 디렉터리는 스킬 밖에 두는 **외부 근거 기록**이다. 문구 품질의 근거는 각 항목이 연결하는 실제 UX 지침·제품 조직의 원저술·국립국어원 자료이며, 이 레포나 다른 에이전트 스킬이 아니다.

[직역체 진단 근거](translationese.md)는 윤문 전에 UI의 의도와 한국어 표현 관습을 대조하는 기준이다. 문법적 특징만으로 진단하지 않는다.

두 책임을 구분한다.

- **[UX 근거](ux.md):** 해당 화면·동작·상태가 사용자에게 무엇을 알려야 하는가.
- **[한국어 윤문 근거](korean.md):** 그 의미를 한국어로 어떻게 정확하고 자연스럽게 표현하는가.

제품 코드·화면·사양은 실제 동작, 조건, 결과를 확인하는 자료다. 좋은 UX나 한국어 문체의 기준으로 승격하지 않는다. 퍼널 전체를 읽는 절차는 사용자가 정한 작업 범위이며, 모든 외부 문서가 그 절차를 명시했다고 주장하지 않는다.

## 기록과 확인 상태

- [sources.json](sources.json): 65개 출처의 ID, 원문 URL, 성격, 확인 위치, 주장, 적용 범위, 한계.
- [sources.md](sources.md): 동일 ID의 직접 앵커와 원문 내용·운영상 해석의 구분.
- 자료 언어: 한국어 62개, 한국어·영어 혼합 1개, 영어 2개. 영어 자료는 공식 지역화 절차를 보완한다.
- 확인일: 2026-10-21. 이 날짜는 확인 시점이며 발행일이나 최신성 보장이 아니다.

`passage-checked`는 기록한 구절을 확인했다는 뜻이다. 전체 문서 검증, 독립적인 사용성 실험, 인간의 승인이나 인증을 의미하지 않는다. `partial`은 공식 게시물·발췌·초록 등 제한된 범위만 확인한 상태다. SRC-042·043·047·050·056이 해당하며, 미확인 세부 규칙·개선문·통계에 의존하는 판단은 보류한다.

같은 KRDS에 속한 22개 페이지(SRC-019~040)는 역할이 다른 문서 22개다. 서로 독립적인 연구 22건이 아니다. 사례·인터뷰·전문가 제안·공식 지침·어문 규범도 동일한 증명력을 가진 것으로 합산하지 않는다.

## 변경을 근거에 연결하기

적용할 때는 원문과 확인 위치를 읽고 적용 조건·예외가 맞는지 확인한다. 문구별 판정에는 UX 역할과 한국어 표현 근거를 필요한 만큼 각각 연결한다. 한 자료가 두 책임을 지원할 수 있으나, 맞춤법만 맞는다는 이유로 좋은 UX라고 판정할 수는 없다.

원문이 명시한 내용과 이 프로젝트의 운영상 해석을 구분한다. 새 규칙은 다른 스킬이나 모델의 취향에서 추가하지 않는다. 출처가 충돌하면 대상·과업·상태·문서 성격을 비교하며, 해결되지 않은 차이를 숨기지 않는다.

원문 전체를 복제하지 않고 필요한 내용을 요약한다. 이후 근거가 바뀌면 URL·확인 위치·주장·범위·한계·확인일을 함께 갱신한다.
