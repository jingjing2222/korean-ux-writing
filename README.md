# Korean UX Writing

한국어 · [English](README.en.md)

프론트엔드의 한국어 문구를 사용자 흐름과 공개된 UX·한국어 기준에 맞춰 다듬는 Agent Skill입니다. 번역투, 불필요한 수식, 모호한 안내를 찾아 고치고, 각 문구의 변경 이유와 근거를 남깁니다.

먼저 사용자 흐름을 읽고 직역체·번역투를 진단합니다. 실제 동작에 맞는 안내를 정한 뒤 자연스러운 한국어로 다듬으며, 이미 적절한 문구는 유지합니다.

## 설치

[Vercel의 skills CLI](https://github.com/vercel-labs/skills)로 설치합니다. Node.js 22.20 이상과 Python 3.10 이상이 필요합니다.

```sh
npx skills add jingjing2222/korean-ux-writing --skill korean-ux-writing
```

Claude Code, Codex 등 Agent Skills를 지원하는 도구에서 사용할 수 있도록 구성했습니다. 설치 위치와 호출 방식은 사용하는 도구에 따라 달라질 수 있습니다.

## 이렇게 요청하세요

전체 프론트엔드를 검토하려면:

```text
korean-ux-writing 스킬로 프론트엔드의 한국어 문구를 전수 검토해 줘.
각 문구의 원문, 개선문, 판단 근거를 1:1로 정리하고 코드에 반영해 줘.
```

특정 흐름부터 시작하려면:

```text
korean-ux-writing 스킬로 회원가입 흐름의 문구를 다듬어 줘.
진입 화면부터 오류 복구와 가입 완료까지 함께 확인해 줘.
```

## 어떻게 진행되나요?

1. **연결된 사용자 흐름을 읽습니다.** 진입점과 앞서 안내한 내용, 선택에 따른 분기, 이탈·오류 복구, 완료 후 결과까지 확인합니다.
2. **검토할 문구를 모읍니다.** 버튼, 입력 안내, 오류, 빈 화면, 알림, 접근성 문구 등을 화면과 상태에 연결합니다.
3. **윤문 전에 번역투를 진단합니다.** 뜻이 통하더라도 영어 표현을 그대로 옮겨 한국어 UI에서 어색해진 단어와 문구를 살핍니다. 실제 행동과 한국어 사용 관습을 함께 확인합니다.
4. **내용과 표현을 차례로 검토합니다.** 코드로 확인한 사실을 바탕으로 필요한 UX 안내를 정하고, 출처가 있는 한국어 기준으로 문장을 다듬습니다.
5. **문구별 결과를 기록하고 확인합니다.** 원문과 결과를 1:1로 연결하고, 변경 근거와 확인한 범위를 남깁니다. 가능한 환경에서 실제 화면도 확인합니다.

모든 문구는 **수정·유지·보류** 중 하나로 기록합니다. 의미와 기능, 변수, 금액·기간·조건 등 중요한 정보를 보존하며, 확인이 부족한 문구는 보류하고 필요한 정보를 적습니다.

## 어떤 근거를 사용하나요?

[증적 문서](docs/evidence/README.md)에 외부 원문과 적용 범위, 예외를 정리했습니다. 증적은 스킬 밖에서 별도로 관리합니다.

- **UX 자료**는 해당 상황에서 무엇을 안내해야 하는지 판단하는 데 씁니다.
- **한국어 자료**는 그 내용을 어떻게 명확하고 자연스럽게 표현할지 판단하는 데 씁니다.
- **제품 코드**는 실제 동작과 조건을 확인하는 데 씁니다.

공식 지침, 사용성 조사, 전문가의 제안은 구분해서 다룹니다. 모든 제품에 해요체나 특정 브랜드의 말투를 일괄 적용하지 않습니다.

## 사용 범위

기존 한국어 UI 문구의 검토와 개선을 위한 스킬입니다. 한국어가 없는 제품의 전체 번역이나 새로운 콘텐츠 작성은 별도 작업이 필요합니다.

검토 결과에는 접근하지 못한 화면과 확인하지 못한 상태도 남깁니다. 자동 검사만으로 모든 문구의 자연스러움이나 사용성을 보장할 수는 없습니다.

실행 절차와 완료 기준은 [SKILL.md](skills/korean-ux-writing/SKILL.md)에서 확인할 수 있습니다.
